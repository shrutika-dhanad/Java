Map: 
in java map elements are stored in key-value pairs, 
keys are unique values asssociated with individual values ,
A map cannot contain a duplicate keys 
and each key is asssociated with a single values.


1.No duplicate keys:each keys can map to at most one value.however, diffrent keys can map to tha same value.
2.Key-value asssociation : it maintains an assosiation of keys to values.
3.implementation: spme of the well-known classes that implement the map interface are (HashMap,TreeMap,LinkedHashMap,
and HashTable).
4.Order: the map interface itself dosent guarantee any specific order of its elements. however, some specific implementations
like treemap maintain a sorted order.
and LinkedHashMap maintains the insertion ordeer.
5.Null values: Maps allow null and depending on the implementation , null keys.for ex-HashMap allows one null key and multiple
null values , but hashtable does not allow null keys or values.
