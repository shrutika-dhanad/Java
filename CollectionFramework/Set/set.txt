In the Java Collections Framework (JCF), Set is an interface that represents a collection that does not allow duplicate elements. 
It models the mathematical concept of a set.

Key Characteristics
No duplicates: A Set contains at most one null element and no two elements e1, e2 such that e1.equals(e2) is true.
Extends Collection: Set inherits all methods from the Collection interface (add, remove, size, contains, iterator, etc.) but
 adds no new methods of its own — it enforces stricter behavior on the inherited ones.
Unordered (generally): Most Set implementations don't guarantee any particular iteration order, though some do.
